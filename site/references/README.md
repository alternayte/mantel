# Reference set

The gauntlet (`BUILD.md` §5) runs twice, and the two runs have opposite bars. This directory is what
both runs are given: the references, the criteria, and one album of real photographs so every
variant is judged on the same content.

`SDD.md` §14.3 listed this as open. It is closed by what is in here.

| File | What it is |
|---|---|
| `viewer.md` | Run A. What the viewer is aiming at, and what it must not become |
| `creator.md` | Run B. What the creator is aiming at |
| `criteria.md` | How a variant is judged. Numbers and tests, never prose |
| `album/` | Thirteen CC0 photographs and one clip. The fixture album |
| `album.json` | Provenance for every photograph |

## How a run uses this

1. Every builder variant gets `viewer.md` or `creator.md`, `criteria.md`, and the hard constraints.
2. Every variant renders the same fixture album. A variant that looks good on one square photograph
   and breaks on the panorama has not been tested, it has been flattered.
3. The critic's verdict is a committed failing test or a measured number. Never prose.
4. The winner is frozen into `DESIGN.md` as tokens plus the reason for each choice.

## The fixture album

Thirteen photographs and one four-second clip, deliberately awkward:

- a panorama at 2.6:1 and two portraits at 4:5 and 3:4, because a grid that only handles landscape
  is not a grid
- a square
- sizes from 683px to 2000px on the long edge, because a real album is not uniform
- subjects that are ordinary rather than beautiful: a market stall, a cafe table, a street. A photo
  book of stock-perfect landscapes hides a weak layout

Every photograph is CC0, and its provenance is in `album.json`. Metadata is stripped from all of
them, as the product does to its own derivatives.

The clip is generated by ffmpeg rather than taken from anyone, so it carries no licence at all.

## Using it as a real album

```
just dev
# sign in, create an album, and upload site/references/album/*
```

The gauntlet judges rendered pages, not mockups, so run the variants against this album through the
real API.
